# أدوات الفحص والتجارب

هذه الملفات لا تُستدعى عند تشغيل التطبيق. شغّلي وحدات Python من جذر MeetSpace باستخدام `python -m backend.checks.<name>`؛ ملفات التشغيل الفعلية بقيت في `backend/`.

| الأداة | الاستخدام | أثر التشغيل |
|---|---|---|
| `benchmark_m4` | قياس Qwen وطلبات المحادثة | يقرأ Firestore ويستدعي النموذج؛ لا يحفظ حجوزات؛ يكتب تقريرًا |
| `verify_selection_readonly` | التحقق من اختيار البطاقة دون النموذج | يقرأ Firestore ولا يؤكد حجزًا؛ يكتب تقريرًا |
| `verify_speed_readonly` | اختبارات الفهم والاختيار والتصحيح | يستدعي Qwen ويقرأ Firestore؛ يمنع تنفيذ الحفظ؛ يكتب تقريرًا |
| `report_m4` | اشتقاق جداول المقارنة من الأدلة | ملفات محلية فقط؛ يكتب نتائج التحليل |
| `audit_m2`, `audit_m3` | تدقيق سجلات تجارب مراحل محددة | يقرأ Firestore ويكتب تقارير؛ يفترض وجود تجهيزات تلك المراحل |
| `verify_live_m2`, `verify_live_m3` | إعادة تجارب حجز فعلية | **ينشئ حجوزات اختبار**؛ M3 يختبر إلغاء تجهيزات جديدة والصيانة وإعادتها |
| `verify_concurrency_m2` | تجربة تأكيد متزامن | **ينشئ حجز اختبار** |
| `check_m4_final` | لقطة تحقق تاريخية عند نهاية M4 | يفترض 17 حجزًا وCSV فارغًا ونسخة prompt سابقة؛ **ليس فحصًا صالحًا للحالة الحالية بعد التجارب البشرية** |

البيانات التاريخية في `docs/evidence/` لا تُستبدل عند إعادة التجارب. استخدمي اسم تقرير جديد إذا كانت الأداة تدعمه؛ الأدوات القديمة ذات المسار الثابت تحتاج تغيير مسار التقرير قبل إعادة تشغيلها. لا تشغّلي أدوات إنشاء الحجوزات كجزء من ترتيب الملفات أو تشغيل التطبيق المعتاد.

مثال قياس للقراءة فقط، باسم تقرير جديد:

```powershell
.\.venv\Scripts\python.exe -m backend.checks.benchmark_m4 --label new_run --prompt backend/prompts/booking_agent.md --trials 2 --output docs/evidence/m4/new_run.json
```

الاختبارات المعزولة التي لا تحتاج خدمة Firestore فعلية موجودة في `backend/tests`:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s backend/tests -t . -v
```
