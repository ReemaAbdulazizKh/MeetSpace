# أدلة الاختبارات والقياسات التقنية

- `m1/`: الاتصال والتهيئة الأساسية.
- `m2/`: تجارب الحجز والتزامن والتدقيق.
- `m3/`: التقويم والإدارة والصيانة والمتصفح.
- `m4/`: مقارنة الأوامر وفحوص الأداء والتحسينات اللاحقة والتدقيق.

نُقلت ملفات JSON كما هي دون تحرير محتواها. قد تحتوي على مسارات وأسماء وحدات Python قديمة في حقول مثل `prompt_path`؛ هذه بيانات عن التجربة وقت تنفيذها، وليست تعليمات تشغيل حالية. الأوامر الحالية في README وأدلة أدوات الفحص، والأوامر السابقة محفوظة في `../archive/prompt_versions/` ونسخ الكود في `../archive/speed_before/`.

هذه أدلة تاريخية وليست إعدادات يقرأها التطبيق عند التشغيل. لا تُستبدل بنتائج تجربة جديدة. ملف القياسات البشرية الأصلي منفصل في `../m4/productivity_results.csv`.
