# الأرشيف

- `prompt_versions/`: الأوامر السابقة والمرشحون المقبولون والمرفوضون؛ تحفظ أدلة مقارنة قبل/بعد.
- `speed_before/`: نسخة ملفات محددة قبل تحسين الأداء، وليست ملفات تشغيل.

حُفظت محتويات النسخ كما هي؛ قد تذكر مسارات قديمة. الملف الفعلي القابل للتعديل هو `backend/prompts/booking_agent.md`، وكود التشغيل في `backend/` و`frontend/src/`. لا تشغّلي كود الأرشيف بدل التطبيق.
