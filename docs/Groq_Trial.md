أذنت المالكة بتجربة Groq بدل Ollama. أضيف خيار مزوّد دون اعتماد مكتبة جديدة أو تغيير قواعد الحجز/Firestore أو البرومبت المعتمد. افتراضيًا يبقى Ollama؛ لم يُنشر المشروع أو يُغيّر قيد العناوين المحلية. هذه خطوة تجربة نموذج، لا تجهيز مكتمل لاستضافة Render.

## الإعداد الخاص

أنشئي المفتاح من https://console.groq.com/keys وأضيفي في `.env` بجذر المشروع **محليًا فقط**:

```dotenv
GROQ_API_KEY=YOUR_PRIVATE_KEY
GROQ_MODEL=qwen/qwen3.8-27b
```

لا ترسلي المفتاح في المحادثة أو GitHub. لقياس الاستخراج دون تفعيل المزود على التطبيق:

```powershell
.venv\Scripts\python.exe -m backend.checks.try_groq
```

البرنامج يستخدم بيانات سياق وهمية، ولا يستورد خدمة Firestore أو ينشئ/يؤكد حجزًا. سجل النتائج المستقل: `docs/evidence/groq/trial.json`. لا يُعد اختبار حفظ أو تعارض فعليًا، ولا قياس إنتاجية بشريًا. إذا غاب المفتاح يكتب `not_run` دون اتصال أو أزمنة مخترعة. يتوقف عند خطأ المزود دون إعادة تلقائية.

بعد نجاح التجربة ومراجعة نتائجها، لتفعيل Groq في التطبيق أضيفي `MODEL_PROVIDER=groq` وأعيدي تشغيل Backend. للعودة: `MODEL_PROVIDER=ollama` ثم إعادة التشغيل. لا يُفعّل التبديل تلقائيًا لمجرد وجود المفتاح. اختيار العرض وتأكيده يخضعان لضوابط الخادم نفسها.

## التغيير والتحقق

- `backend/config.py`: خيار `MODEL_PROVIDER` واسم نموذج Groq والمفتاح؛ أسماء فقط في `.env.example`.
- `backend/agent.py`: HTTPS إلى Groq، JSON object mode ثم Pydantic صارم؛ رفض نقص/فساد/قطع المخرج، وفصل مصدر الرد. لا تسجيل لمفتاح أو جسم خطأ المزود.
- `backend/connectivity.py` و`routes.py`: فحص المزود المحدد؛ حقل `ollama` القديم في health أبقي للتوافق، مع `model_provider` لتحديد المزود الفعلي. فحص قائمة النماذج لا يثبت صحة الاستخراج.
- `backend/schemas.py`: قبول مصدر الرد `groq`؛ شريط اتصال الواجهة يسمي المزود الفعلي دون تغيير التصميم.
- اختبارات معزولة للترويسة والعنوان وJSON غير الصالح والقطع وغياب المفتاح وHTTP429 الآمن؛ لا تحل محل اختبار API فعلي بمفتاح.

لا تُنسب قياسات Ollama التاريخية إلى هذا النموذج. العرض وحزمة المصادر السابقة يمثلان النسخة السابقة، ولم يعاد توليدهما لتصوير التجربة كإنجاز مكتمل. نصوص الطلب ستُرسل إلى Groq عند استخدامه، وليست معالجة محلية؛ بيانات وهمية فقط أثناء التجربة.

المراجع الرسمية التي روجعت: [نموذج Qwen](https://console.groq.com/docs/model/qwen/qwen3.8-27b)، [JSON والتحقق](https://console.groq.com/docs/structured-outputs). النموذج Preview؛ توافره لحساب بعينه لا يثبت قبل اتصال فعلي. لا يُستخدم نجاح اختبار وهمي لإعلان نجاحه.
